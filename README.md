# Credit card Fraud Analytics Dashboard Using ML & Power BI
![main_img](/assets/Fraud Analytics Dashboard Performance & Insights.jpg)

## Overview:
This project delivers a machine learning–powered fraud detection system with interactive dashboards for real-time monitoring and analysis of transactions. It identifies high-risk transactions and provides actionable insights to prevent fraud.

## Key Features:

- Data Management: Processed and analyzed large transactional datasets using Google BigQuery and SQL.
- Machine Learning: Trained and validated models including XGBoost, Random Forest, and Balanced Bagging with a focus on catching fraudulent transactions.

- Explainable AI: Used SHAP analysis to interpret model predictions and highlight key features driving fraud.

- Interactive Dashboards: Created two Power BI dashboards with KPIs, charts, and slicers for dynamic insights and decision support.

- Technologies: Python, scikit-learn, XGBoost, SHAP, Google BigQuery, SQL, Power BI

## Outcome:

- Accurate fraud detection with interpretable model insights.
- Fully functional dashboards enabling proactive monitoring and fraud prevention strategies.
